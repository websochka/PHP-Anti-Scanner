# PHP Anti-Scanner

**PHP Anti-Scanner** — простой PHP-скрипт для автоматической защиты сайтов от хакерских сканеров, ботов и массового перебора уязвимых файлов. Скрипт анализирует подозрительные запросы к несуществующим URL и автоматически блокирует IP-адреса через `.htaccess`.

Проект основан на практическом подходе из статьи:

https://sochka.com/yak-khakery-shukaiut-vrazlyvosti-u-saytakh-i-iak-tsomu-zapobihty.html

## Короткое описание

Автоматический защитный скрипт для сайтов на PHP. Он помогает блокировать подозрительных ботов, которые ищут уязвимые файлы вроде `c4.php`, `l.php`, `up.php`, `phpinfo.php`, старые бэкапы, web shell и другие типовые точки входа.

![Подозрительные запросы на сайте](https://sochka.com/wp-content/uploads/2025/11/403.jpg)

## Что делает скрипт

- Проверяет текущий URL запроса.
- Сравнивает его с базой подозрительных путей.
- Загружает свежую базу сигнатур из удаленного JSON-источника.
- Кеширует базу локально, чтобы не делать сетевой запрос на каждом открытии 404-страницы.
- При совпадении добавляет IP-адрес посетителя в `.htaccess`.
- Возвращает ответ `403 Forbidden`.
- Снижает нагрузку от автоматического сканирования.

## Когда это полезно

Скрипт полезен, если в access-логах сайта регулярно появляются множественные запросы вида:

```text
GET /667.php HTTP/1.0
GET /c4.php HTTP/1.0
GET /racs3.php HTTP/1.0
GET /phpinfo.php HTTP/1.1
GET /.well-known/setup HTTP/1.1
```

Обычно такие запросы делают автоматические сканеры, которые ищут старые уязвимые файлы, тестовые скрипты, бэкапы, web shell, ошибки в CMS или плагинах.

## Быстрый старт для WordPress

1. Скопируйте файл [src/anti-scanner.php](src/anti-scanner.php) в тему или подключите его из `404.php`.
2. Откройте файл вашей темы:

```text
/wp-content/themes/ваша_тема/404.php
```

3. В самый верх файла, до вывода HTML, добавьте:

```php
<?php
require_once __DIR__ . '/anti-scanner.php';
```

4. Убедитесь, что PHP имеет право записи в корневой `.htaccess`.
5. Проверьте работу на тестовом URL, который есть в базе подозрительных путей.

Подробная инструкция: [docs/INSTALL.md](docs/INSTALL.md)

## Конфигурация по умолчанию

В [src/anti-scanner.php](src/anti-scanner.php) используются настройки:

```php
$jsonUrl = 'https://shell.seotools.workers.dev';
$localFile = __DIR__ . '/suspicious-paths.json';
$cacheLifetime = 24 * 60 * 60;
$htaccessFile = rtrim($_SERVER['DOCUMENT_ROOT'], '/') . '/.htaccess';
```

Это означает:

- база подозрительных путей обновляется раз в сутки;
- локальный кеш хранится рядом со скриптом;
- IP-адреса блокируются через `.htaccess` в корне сайта.

## Важные требования

- PHP 7.4 или выше.
- Apache с поддержкой `.htaccess`.
- Включенный `mod_rewrite` не обязателен, но `.htaccess` должен обрабатываться сервером.
- У PHP должны быть права на запись в `.htaccess`.
- Скрипт должен выполняться до вывода HTML.

## Безопасность

Скрипт предназначен для защиты от массового автоматического сканирования. Это не замена полноценному WAF, обновлениям CMS, резервному копированию и настройке прав доступа.

Перед установкой на боевой сайт:

- сделайте резервную копию `.htaccess`;
- протестируйте на копии сайта;
- проверьте, что ваш IP не попал в блокировку;
- убедитесь, что критически важные URL не указаны в базе подозрительных путей.

Подробнее: [docs/SECURITY.md](docs/SECURITY.md)
