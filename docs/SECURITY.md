# Безопасность и ограничения

PHP Anti-Scanner предназначен для автоматической реакции на массовые запросы к подозрительным URL. Он помогает снизить нагрузку и быстро блокировать IP-адреса сканеров, но не заменяет полноценную систему безопасности.

## Что проект защищает

- Массовые обращения к типовым web shell и PHP-файлам.
- Поиск `phpinfo.php`, старых бэкапов и тестовых скриптов.
- Повторяющиеся запросы к несуществующим файлам.
- Автоматическое сканирование структуры сайта.

## Что проект не делает

- Не исправляет уязвимости CMS, плагинов или тем.
- Не заменяет обновления WordPress, OpenCart, Joomla или других систем.
- Не анализирует тело POST-запросов.
- Не защищает от сложных таргетированных атак.
- Не заменяет WAF, fail2ban, ModSecurity или серверные firewall-правила.

## Риски

Автоматическая запись в `.htaccess` требует аккуратности:

- ошибка в `.htaccess` может нарушить работу сайта;
- при неправильной базе сигнатур можно заблокировать легитимного пользователя;
- если PHP не имеет прав записи, блокировка не сработает;
- большое количество IP в `.htaccess` может усложнить поддержку файла.

## Рекомендации

- Сделайте резервную копию `.htaccess` перед установкой.
- Проверьте работу на тестовом сайте.
- Регулярно просматривайте добавленные IP-адреса.
- Не используйте скрипт как единственную меру защиты.
- Обновляйте CMS, плагины, темы и PHP.
- Ограничьте доступ к административным разделам.
- Используйте сложные пароли и двухфакторную аутентификацию.

## Как разблокировать IP

Откройте `.htaccess` и найдите блок:

```text
# BEGIN PHP Anti-Scanner
...
# END PHP Anti-Scanner
```

Удалите строку с нужным IP:

```text
Deny from 192.0.2.10
```

Для Apache 2.4 также удалите соответствующую строку:

```text
Require not ip 192.0.2.10
```
