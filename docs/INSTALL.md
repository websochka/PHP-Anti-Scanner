# Установка PHP Anti-Scanner

## Установка на WordPress

1. Скопируйте файл `src/anti-scanner.php` в папку активной темы WordPress.

Пример:

```text
/wp-content/themes/your-theme/anti-scanner.php
```

2. Откройте файл:

```text
/wp-content/themes/your-theme/404.php
```

3. Вставьте подключение в самый верх файла:

```php
<?php
require_once __DIR__ . '/anti-scanner.php';
```

Важно: подключение должно стоять до `get_header()`, HTML-разметки, пробелов и любого вывода в браузер.

4. Убедитесь, что PHP может записывать изменения в корневой `.htaccess`.

5. Откройте заведомо подозрительный URL из тестовой базы, например:

```text
https://example.com/c4.php
```

Если путь есть в базе сигнатур, скрипт должен вернуть `403 Forbidden`, а IP должен появиться в `.htaccess`.

## Установка на обычный PHP-сайт

1. Скопируйте `src/anti-scanner.php` в проект.
2. Подключите файл в обработчике 404-ошибок или в самом начале фронт-контроллера.

Пример:

```php
<?php
require_once __DIR__ . '/src/anti-scanner.php';
```

3. Настройте сервер так, чтобы несуществующие страницы попадали в PHP-обработчик 404.

## Проверка прав

Скрипт должен иметь возможность:

- создать или обновить `suspicious-paths.json`;
- прочитать и изменить корневой `.htaccess`.

Если `.htaccess` не меняется, проверьте владельца файлов и права записи.

## Где хранится кеш сигнатур

По умолчанию кеш создается рядом со скриптом:

```text
src/suspicious-paths.json
```

База обновляется раз в сутки.

## Как откатить изменения

1. Удалите подключение `anti-scanner.php` из `404.php`.
2. Откройте `.htaccess`.
3. Удалите блок между строками:

```text
# BEGIN PHP Anti-Scanner
# END PHP Anti-Scanner
```

4. Сохраните файл.
